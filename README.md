# CLASSICA LOID ― 薔薇の棺と、愛の旋律 ―

架空のテレビアニメ作品を題材にした、ファンメイドの公式サイト風ポータルです。

## GitHub Pages
このリポジトリの `main` ブランチのルートを公開元に設定してください。
GitHub の **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)** を選択すると公開できます。

## Files
- `index.html` — トップページ
- `assets/css/style.css` — 共通デザイン・レスポンシブスタイル
- `assets/js/main.js` — モバイルナビゲーション
- `.nojekyll` — Pages の Jekyll 処理を無効化

## Design
Ivory / Antique Gold / Deep Rose を基調にしたクラシカル・ゴシック・ロマンティックなデザインです。PC・タブレット・スマートフォンに対応しています。
